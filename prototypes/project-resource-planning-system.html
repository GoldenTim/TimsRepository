项目维度汇总（PDTL 视图） 模块 3

面向 PDTL / PM，从项目维度查看总需求、设计/验证/实现等领域 GAP、需求与可用资源，辅助识别项目群规划阶段的资源缺口与高风险项目。

项目名称领域状态版本 评估人力(人月)实际人力(人月)GAP(人月)风险里程碑操作
高风险：GAP ≤ −8 人月 中风险：−8 < GAP ≤ −3 低风险：GAP > −3
月度 GAP 趋势（近 6 个月）
单位：人月

颜色越深表示缺口越大；点击单元格可查看该月明细。系统在里程碑、工时需求、部门资源池变更后自动重算并刷新本视图。

部门维度汇总 模块 4

面向部门经理，查看评估人力、实际人力、GAP、主要缺口项目与风险说明。部门资源调整后实时反映到本部门负载及关联项目 GAP。

部门负责人评估人力(人月)实际人力(人月)GAP(人月)负载率主要缺口项目风险说明
项目里程碑管理（PMO 视图） 模块 5

由 PMO / MKT 维护项目关键里程碑节点。里程碑变更后触发版本记录，并联动刷新项目工时与 GAP 结果。

里程碑计划日期实际日期状态负责人关联工时变更
工时需求投入（研发填报入口） 模块 6

由研发三级部门按项目、月份填报设计/验证/实现工时需求（单位 H）。系统按 200H = 1 人月换算为评估人力，作为项目与部门 GAP 计算的核心输入。

项目部门月份设计(H)验证(H)实现(H)合计(H)评估人力(人月)状态
换算规则：评估人力 = 合计工时 ÷ 200 H/人月。填报提交后自动联动项目维度与部门维度 GAP 重算。
部门资源池 模块 7

由部门经理维护当前可投入研发人力。系统基于折算后可投入人力自动计算部门供给能力，支持预算刷新、工时调整、资源调配记录。

部门总人力实习PM折算请假待补充HC可投入人力(人月)折算率最近调整
TR 偏差分析 模块 8

沉淀项目在 TR 阶段的评估工时、实际工时、偏差、偏差率与偏差原因，反哺后续项目工时评估，提高项目群资源规划准确性。

项目TR阶段评估工时(H)实际工时(H)偏差(H)偏差率偏差原因反哺建议
核心业务规则 模块 10

GAP 计算

GAP = 评估人力 − 实际人力。负值表示资源缺口，正值表示资源富余。

GAP = est_headcount − actual_headcount

风险阈值

高风险GAP ≤ −8 人月
中风险−8 < GAP ≤ −3 人月
低风险GAP > −3 人月

刷新机制

支持按需刷新，每次刷新生成独立版本记录；部门预算刷新可选审批。

数据联动

里程碑、工时需求、部门资源池变更后，项目维度与部门维度 GAP 自动重算。

版本日志 模块 9

自动记录所有关键变更，包括版本、日期、更新人、更新类型、涉及项目/模块、变更前后数据。支持历史版本追溯与差异对比。
